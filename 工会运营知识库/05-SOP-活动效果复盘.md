# 1.5 活动/联动效果复盘 SOP

> **触发条件**：任何活动（生日会、企划回、联动PK、周年庆、首秀等）结束后 48 小时内

---

## 活动前：设定目标（必须在活动前填好）

**没有目标的复盘没有意义。** 活动策划阶段就要定好：

| 目标类型 | 目标值 | 测量方式 |
|----------|--------|---------|
| 营收目标 | XX 元 | 当天礼物 + 心愿礼物 + 粉丝团新增 |
| 人气目标 | 观看人次 XX / 峰值在线 XX | 直播后台 |
| 涨粉目标 | 新增粉丝 XX | 抖音后台 |
| 传播目标 | 短视频播放量 XX / 作品点赞 XX | 抖音统计 |
| 粉丝团目标 | 新增粉丝团 XX 人 | 直播后台 |

## 定性复盘

### 做对了什么

```
1. （至少写 3 条，具体的，不是「主播表现好」这种废话）
   - 例：提前一周发预告作品，悬念式宣发有效，活动前涨了 500 粉丝
   - 例：设计了「粉丝投票选歌」互动环节，评论参与率比平时高 3 倍
   - 例：提前通知了榜上大哥活动时间，当天所有大哥全部到场
```

### 做错了什么

```
1. （至少写 2 条，坦诚的，不追究但必须记录）
   - 例：开场拖了 15 分钟调试设备，流量高峰被浪费
   - 例：没有安排短视频团队实时发活动高光切片，错过流量窗口
   - 例：PK 环节惩罚设计太温和，没制造出节目效果
```
