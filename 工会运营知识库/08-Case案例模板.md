# 3.1 Case 案例模板

> **规则**：每个问题解决后 24 小时内填写。先完成再完美，写了就比没写强。

---

## 模板

```
━━━━━━━━━━━━━━━━━━━━━━━━
【Case 编号】YYYY-MM-XXX（年份-月份-序号，如 2026-07-001）
【提交人】
【日期】

【问题描述】
（发生了什么？一句话说清楚）

【涉及主播】
（单人 or 多人？）

【用了哪个 SOP？】
（1.1 / 1.2 / 1.3 / 1.4 / 1.5 / 无匹配SOP，以下是自主排查）

【排查过程】
（按 SOP checklist 走了哪几步？发现了什么？）

【数据支撑】
（附截图或关键数据）

【根因判断】
（不要写「综合因素导致」，必须指出最核心的 1-2 个原因）

【解决方案】
（具体做了什么，谁做的，什么时间完成的）

【结果验证】
（方案执行后的数据变化。如果是长期方案，标注下次检查时间）

【复盘】
- 做对了什么：
- 做错了什么：
- 如果再来一次会怎么改：
- 是否需要更新某个 SOP：

━━━━━━━━━━━━━━━━━━━━━━━━
```

---

## 示例（写好给运营看的标杆）

```
━━━━━━━━━━━━━━━━━━━━━━━━
【Case 编号】2026-07-001
【提交人】小王
【日期】2026.07.12

【问题描述】
主播「星野」近一周场均礼物收入从 3500 跌到 1800，跌幅 48%

【涉及主播】
星野（单人）

【用了哪个 SOP？】
1.1 主播数据下滑排查

【排查过程】
Step 1 锁定指标：礼物收入 -48%，评论率基本持平，观看人次 -12%
→ 判断：收入暴跌 + 观看小跌 + 评论正常 = 大概率是大哥流失，不是内容问题

Step 2 四维度排查：
- 内容端：主题/时段/画面质量均无变化 ✓
- 用户端：榜3大哥「老板A」7天未出现，查了私信和粉丝群记录，最后互动是7.1，之后无任何互动
- 竞品端：同赛道无新主播崛起
- 主播端：主播状态正常，自述无异常

Step 3 匹配策略：大哥流失 → 运营主动联系

【数据支撑】
（这里贴 7 天收入趋势截图 + 榜10付费用户活跃度表截图）

【根因判断】
榜3大哥「老板A」流失，此人此前贡献星野月营收约 30%

【解决方案】
1. 7.12 运营私信老板A，语气关心不推销，了解离开原因
2. 了解到对方是工作忙没时间看直播，不是对主播不满
3. 7.13 星野发了一条抖音日常感谢老板A一直以来的支持（不提离开的事，只表达感谢）
4. 同时启动了「粉丝团福利升级」计划，增加粉丝团专属内容和权益，降低对单个大哥的依赖

【结果验证】
- 老板A 7.15 回归，虽然频率下降但没完全流失
- 粉丝团福利升级后，一周内新增 8 个粉丝团成员
- 7.19 周收入恢复至 2900，恢复至下滑前 83%

【复盘】
- 做对了什么：发现大哥流失后没有催促主播加播冲业绩，而是先搞清楚人为什么走
- 做错了什么：对大哥的流失预警太滞后，应该建一个付费用户活跃度监控，大哥超过 3 天不互动就预警
- 如果再来一次：提前建好大哥预警机制，在大哥刚开始减少互动时就主动联系
- 是否需要更新某个 SOP：建议在 SOP 1.1 中增加「大哥预警触发条件：核心付费用户超过3天无互动自动标记」

━━━━━━━━━━━━━━━━━━━━━━━━
```

## 案例归档方式

在飞书知识库「3.2 案例库」下，按月建子页面：
```
3.2 案例库/
├── 2026-07/
│   ├── 001-星野收入暴跌-大哥流失
│   ├── 002-...
├── 2026-08/
...
```

每周例会选 1-2 个 Case 过一遍，管理层点评。质量高的置顶加精。
