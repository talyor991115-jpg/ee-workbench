# 1.3 主播状态异常处理 SOP

> **触发条件**：主播出现断播、直播质量骤降、情绪异常、粉丝投诉、要求解约等非数据类异常

---

## 异常分级

| 级别 | 表现 | 响应时限 | 是否上报管理层 |
|------|------|---------|--------------|
| 🟡 轻微 | 话变少、迟到 1-2 次、短视频停更 2-3 天 | 24h 内沟通 | 不需要 |
| 🟠 中等 | 连续断播 3 天以上、直播中情绪失控、粉丝群吵架 | 4h 内沟通 | 沟通后同步结果 |
| 🔴 严重 | 公开表示想停播、涉及法律风险、重大负面舆情 | 1h 内响应 | 立即上报 |

---

## 处理流程

### 🟡 轻微异常

```
1. 私信关心（非正式，不要用工作语气）
   "最近看你状态好像不太对，需不需要聊聊？不是催你播，就是关心一下"

2. 判断原因 → 给支持
   - 单纯累了 → "要不要休息两天？短视频我帮你顶上"
   - 数据焦虑 → 用数据帮她分析（参考 SOP 1.1）
   - 创作瓶颈 → 一起脑暴新内容方向

3. 记录到主播个人档案（内部，不给主播看）
```

### 🟠 中等异常

```
1. 尽快沟通，可以用语音/电话，比文字有效
   
2. 沟通框架：
   - 先说观察到的现象（不带评判）
   - 问她的感受和真实原因
   - 一起商量解决方案
   - 约定下次检查节点

3. 处理完写 Case 记录
```

### 🔴 严重异常

```
1. 立即上报管理层
2. 在管理层给出方向前，不对主播做任何承诺
3. 涉及法律/合同的，等专业意见，不自行判断
4. 舆情类的：同步启动控评、出声明（管理层审批后发）
```

## 常见场景速查

| 场景 | 常见原因 | 处理要点 |
|------|---------|---------|
| 突然断播 | 三次元有事、心态崩了、在跟别家谈 | 先联系上人，判断严重程度。联系不上超过 48h 升级上报 |
| 直播中哭/情绪失控 | 被黑子搞心态、个人生活问题、长期压榨疲劳 | 下播后沟通，短期减播+心理支持。如果是被网暴，启动维权流程 |
| 频繁抱怨收入 | 实际收入下降 or 预期不符 | 用数据说话+帮她做增收计划（调整内容/时段/引导付费） |
| 要求降低分成 | 可能是被别家挖、或在试探 | 不急着答应也不拒绝，先了解动机。同步上报管理层 |
| 粉丝群内战 | 粉丝派系对立、大哥之间争风吃醋 | 主播出面定调，运营配合控评。立场要快、态度要软 |
| 提出解约/停播 | 大概率已经想了很久 | 了解真实原因（收入/发展/矛盾/挖角），判断是否可挽回 |
| PK 被打狠了心态崩 | 被对面主播或粉丝嘲讽 | 短期减少 PK，调整对手选择策略，做心理建设 |
| 短视频数据焦虑 | 发了好几条都没流量 | 帮分析抖音算法偏好，调整内容方向，不要盲目怼量 |
