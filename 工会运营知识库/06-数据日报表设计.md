# 2.1 工会数据日报 — 飞书多维表格设计

## 使用方式

在飞书新建「多维表格」，按下方设计建表和视图。每天花 10 分钟填数据。

---

## 表结构

### 表1：主播数据日报

每条记录 = 一个主播的一天

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 日期 | 日期 | |
| 主播名 | 文本 | |
| 直播时长(min) | 数字 | |
| 观看人次 | 数字 | |
| 峰值在线 | 数字 | |
| 评论数 | 数字 | |
| 点赞数 | 数字 | |
| 礼物收入(元) | 数字 | 含心愿礼物 |
| 新增粉丝团 | 数字 | 当天新增的粉丝团成员数 |
| 新增粉丝 | 数字 | |
| 掉粉数 | 数字 | |
| 付费人数 | 数字 | |
| ARPU(元) | 公式 | 礼物收入 ÷ 付费人数 |
| 互动率 | 公式 | 评论数 ÷ 观看人次 |
| 分享次数 | 数字 | |
| 是否打PK | 单选 | 是/否 |
| PK收入(元) | 数字 | PK时段的礼物收入 |
| 备注 | 文本 | 异常事件记录（如「抖音推荐流量」「换了新皮」「热榜话题」） |

### 表2：营收汇总日报

每条记录 = 工会一天的总数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 日期 | 日期 | |
| 开播主播数 | 数字 | |
| 总礼物收入(元) | 数字 | |
| PK收入占比 | 公式 | PK收入总额 ÷ 总礼物收入 |
| 大额礼物占比 | 公式 | 单笔500元以上 ÷ 总礼物收入 |
| Top1占比 | 公式 | 最高主播收入 ÷ 总收入 |
| Top3占比 | 公式 | 前三总和 ÷ 总收入 |
| 总付费人数 | 数字 | |
| 新增粉丝团数 | 数字 | |
| 环比变化 | 公式 | (当日总收入 - 前日总收入) ÷ 前日总收入 |

### 表3：主播周报

每条记录 = 一个主播的一周汇总

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 周次 | 文本 | 如「W28」 |
| 主播名 | 文本 | |
| 开播天数 | 数字 | |
| 总直播时长(min) | 数字 | |
| 周总礼物收入(元) | 数字 | |
| 日均收入(元) | 公式 | |
| 周新增粉丝 | 数字 | |
| 周掉粉数 | 数字 | |
| 净增粉丝 | 公式 | 新增粉丝 - 掉粉数 |
| 周新增粉丝团 | 数字 | |
| 短视频发布数 | 数字 | |
| 短视频总播放量 | 数字 | |
| 环比上周收入 | 公式 | (本周 - 上周) ÷ 上周 |
| 运营备注 | 文本 | |

---

## 视图设置

创建以下视图，方便快速查看：

1. **按主播看**：按「主播名」分组，显示最近 7 天
2. **异常预警**：筛选「环比变化」< -20%，标红显示
3. **周报视图**：从表3生成，每周一导出上周数据
4. **PK 效果视图**：按「是否打PK」筛选，对比 PK 日 vs 非 PK 日收入差异

---

## 数据来源

手动填入，来源：
- 抖音：直播后台 → 直播数据 → 单场数据复盘
- 第三方平台：蝉妈妈、飞瓜等（如工会有预算）

自动化方向（远期）：如支持 API，用飞书机器人自动拉数据。初期手动填，先跑通流程。
