# 工会运营知识库 — 搭建说明

## 飞书知识库结构

在飞书创建知识库「XX工会运营作战手册」，按以下目录建页面：

```
📁 1. 决策框架（SOP）
   ├── 1.1 主播数据下滑排查
   ├── 1.2 新主播签约评估
   ├── 1.3 主播状态异常处理
   ├── 1.4 营收波动分析
   └── 1.5 活动/联动效果复盘

📁 2. 数据基建
   ├── 2.1 工会数据日报（多维表格）
   └── 2.2 数据解读指南

📁 3. 案例沉淀（Case Bank）
   └── 3.1 Case 模板
   └── 3.2 案例库（按周归档）

📁 4. 行业情报
   ├── 4.1 头部主播数据追踪
   ├── 4.2 平台政策变动记录
   └── 4.3 竞品工会观察
```

## 权限设置

- 知识库：全员可查看、可编辑
- 数据日报多维表格：全员可编辑
- 案例库：全员可新增，不允许删除他人内容

## 使用规则（写在知识库首页置顶）

> **遇到问题，先跑SOP，再写Case，最后找管理层。**
>
> 三条铁律：
> 1. 找管理层汇报问题前，必须先附上对应 SOP 的排查结果 + 数据
> 2. 每个问题解决后 24 小时内写 Case 记录，模板在 3.1
> 3. 每周五下班前更新自己负责主播的数据追踪
