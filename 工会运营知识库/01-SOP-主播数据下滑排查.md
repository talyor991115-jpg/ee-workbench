# 1.1 主播数据下滑排查 SOP

> **触发条件**：主播任一项核心指标连续 3 天环比下跌超 15%，或单日暴跌超 30%

---

## Step 1：锁定问题指标（5 分钟）

先明确到底什么跌了，不要凭感觉说「最近不太行」：

| 指标 | 当前值 | 7天前 | 跌幅 | 是否异常 |
|------|--------|-------|------|----------|
| 场均直播时长 | | | | |
| 场均礼物收入 | | | | |
| 场均评论数 | | | | |
| 场均新增粉丝 | | | | |
| 场均观看人次 | | | | |
| 场均付费人数 | | | | |
| 场均点赞数 | | | | |

**判断规则**：
- 只有 1 个指标跌 → 可能是单一因素，优先排查该指标关联项
- 多个指标同时跌 → 大概率是内容或主播侧出了问题
- 礼物收入跌但评论没跌 → 可能是大哥流失，不是内容问题

## Step 2：四维度排查（20 分钟）

### 维度一：内容端

| 排查项 | 正常否 | 备注 |
|--------|--------|------|
| 最近 3 场直播主题有无大变？ | | |
| 直播时间段是否变动？ | | |
| 聊天/PK/才艺等内容比例是否变化？ | | |
| 是否有断播、迟到、早退？ | | |
| 直播画面/声音/美颜有无问题？ | | |
| 短视频更新频率是否下降？ | | |
| 是否减少了 PK 连麦频次？ | | |

### 维度二：用户端

| 排查项 | 正常否 | 备注 |
|--------|--------|------|
| 榜 Top 10 付费用户最近 7 天活跃度？ | | |
| 是否有大哥/大姐流失？（查私信/粉丝群互动记录） | | |
| 新增粉丝的互动转化率？（关注→评论→付费） | | |
| 粉丝群活跃度有无变化？ | | |
| 是否有负面节奏或节奏苗头？ | | |
| 粉丝团新增 vs 退出数据？ | | |

### 维度三：竞品/平台端

| 排查项 | 正常否 | 备注 |
|--------|--------|------|
| 同赛道有没有新主播崛起抢流量？ | | |
| 抖音近期有无算法调整/活动分流？ | | |
| 同工会其他主播数据是否也下滑？（判断是个例还是系统性） | | |
| 抖音热榜话题是否转移了观众注意力？ | | |

### 维度四：主播端

| 排查项 | 正常否 | 备注 |
|--------|--------|------|
| 主播近期状态如何？（直接沟通确认） | | |
| 有无个人事务影响？（搬家/生病/考试等） | | |

| 直播热情是否下降？（话变少、互动变敷衍） | | |
| 是否有跳槽/停播风声？ | | |

---

## Step 3：匹配策略

根据排查结果，从下方策略表选对应方案：

| 问题类型 | 建议方案 | 预期见效周期 |
|----------|----------|------------|
| 内容疲劳 | 策划新主题/联动/PK新对手/才艺突破，给主播出新话术 | 1-2 周 |
| 时间段不佳 | 做 A/B 测试，换 2-3 个时段各播一周对比数据 | 1 周可看到趋势 |
| 大哥流失 | 运营主动私信关怀（不是推销，是关心），了解流失原因 | 即时触达，效果视情况 |
| 短视频引流不足 | 加大短视频产出和投放，出 3-5 条高光片段投抖加 | 3-5 天 |
| 平台流量变化 | 调整内容迎合当前热榜话题，短期蹭热度止损 | 即时 |
| PK 效果变差 | 换 PK 对手、调整 PK 频次和惩罚设计 | 1-3 天 |
| 主播状态问题 | 安排休息调整，减播不减质量，运营加强心理支持 | 1-2 周 |
| 竞品冲击 | 分析竞品优势，找出差异化方向，不做正面硬刚 | 持续 |
| 粉丝氛围恶化 | 主播正面回应/发作品定调，运营控评引导 | 即时-3天 |

## Step 4：输出诊断报告

用下方模板，写到 Case 记录里：

```
【主播】XXX
【异常发现时间】X月X日
【核心异常指标】礼物收入 -32%，评论数 -18%
【排查结论】
  - 内容端：最近从PK转聊天，聊天场评论低40%，属正常差异
  - 用户端：榜3大哥「XXX」7天未出现，疑似流失
  - 竞品端：同赛道新主播「XXX」一周涨粉2万，分流明显
  - 主播端：主播自述最近状态不好，直播动力不足
【根因】大哥流失 + 主播状态下滑叠加
【建议方案】
  1. 运营联系「XXX」了解情况（今日完成）
  2. 给主播安排3天休息，期间用短视频维持曝光
  3. 回归后策划一次联动PK拉新观众
【预期效果】2周内礼物收入恢复至下滑前80%水平
【实际结果】（执行后填写）
```

## 管理层介入判断标准

以下情况才需要上报管理层：
- 排查后仍无法定位根因
- 连续 2 周按方案执行后数据无改善
- 涉及主播解约/法律风险/重大负面舆情
- 涉及预算追加（抖加投放/活动经费）

**其他情况：运营自己按 SOP 处理，写 Case，管理层只看 Case 质量。**
