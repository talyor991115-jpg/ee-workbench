# 4. 行业情报追踪

---

## 4.1 头部主播数据追踪

> **目的**：知道行业天花板在哪，学习头部主播的做法，发现趋势

### 追踪表设计（飞书多维表格）

| 字段 | 说明 |
|------|------|
| 主播名 | |
| 所属工会 | |
| 赛道 | 歌势/聊天/才艺/PK型/虚拟偶像 |
| 粉丝数 | 每月更新 |
| 近30天涨粉 | |
| 场均观看人次 | |
| 场均礼物收入(估) | 根据榜单和礼物数据估算 |
| 粉丝团人数 | |
| 内容特点 | 一句话总结差异化 |
| 短视频风格 | 走什么路线？更新频率？ |
| 值得学习的点 | 具体做法（话术/PK技巧/短视频套路/粉丝维护方式） |
| 最近动态 | 有无新企划/联动/转型/争议事件 |

### 追踪频率
- 每月更新一次数据
- 看到值得关注的新主播随时添加
- 重点关注：同赛道突然窜起的新主播（研究她做对了什么）

## 4.2 平台政策变动记录

> **目的**：第一时间知道抖音规则变化，避免踩坑，抓住红利

### 记录模板

```
【日期】
【变动类型】分成政策 / 推荐机制 / 内容审核 / 直播规则 / 虚拟主播相关
【具体内容】
【对工会的影响】
【应对动作】
```

### 关注来源
- 抖音：直播小助手、创作者学院、官方公告
- 行业群/媒体：虚拟主播相关社群、行业公众号
- 第三方数据平台：蝉妈妈、飞瓜等行业报告

## 4.3 竞品工会观察

> **目的**：知道同行在做什么，不错过趋势也不盲目跟风

### 追踪维度

| 维度 | 关注点 |
|------|--------|
| 签约动作 | 最近签了谁？什么类型的主播？从哪挖的？ |
| 运营玩法 | 有什么新企划/新变现方式/PK新套路？ |
| 短视频策略 | 怎么做短视频矩阵？什么类型的视频流量好？ |
| 技术投入 | 有没有用新工具（AI形象/新直播玩法）？ |
| 主播流动 | 有没有别家主播跳过来/自家跳出去？为什么？ |
| 投放策略 | 抖加/千川怎么投？什么素材效果好？ |

### 更新频率
- 有值得关注的事件时随手记
- 每月汇总一次「本月行业动态」

### 记录模板

```
【日期】
【工会名称】
【事件】
【分析】（对行业有什么影响？我们需要跟进吗？）
【行动建议】
```

---

## 使用规则

- 不要求每人每天都看，但**每周至少贡献一条**
- 看到有价值的信息直接填进去，附上来源链接
- 管理层每周扫一眼，有价值的信息在周会上同步
