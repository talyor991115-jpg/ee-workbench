# 1.2 新主播签约评估 SOP

> **触发条件**：收到新主播签约意向 / 主动挖掘到潜力主播

---

## Step 1：数据初筛（硬指标）

先过门槛，不够的直接 pass，不浪费精力：

| 指标 | 签约门槛 | 重点培养线 | 数据来源 |
|------|---------|-----------|---------|
| 粉丝数 | ≥5,000 | ≥30,000 | 抖音主页 |
| 近30天涨粉 | 正增长 | ≥5,000 | 抖音数据平台 |
| 近7天场均礼物收入 | ≥500元 | ≥2,000元 | 直播数据后台 |
| 评论互动率 | ≥3% | ≥8% | 评论数÷观看人次 |
| 近14天开播天数 | ≥6天 | ≥10天 | 直播记录 |
| 有无断播超过7天 | 无 | 无 | 历史记录 |

**判断**：5 项达标 = 可评估，4 项达标 = 观察，3 项及以下 = 暂不考虑

---

## Step 2：内容评估（软实力）

找 3 场典型直播完整看完（倍速），填下表：

| 评估项 | 评分(1-5) | 说明 |
|--------|-----------|------|
| 人设清晰度 | | 一句话能说清这个主播是什么定位吗？ |
| 差异化程度 | | 同赛道里有没有明显区别于其他人的点？ |
| 直播节奏 | | 冷场多吗？话题切换自然吗？留人能力强吗？ |
| 声音/形象条件 | | 是否符合目标受众审美？ |
| 粉丝互动质量 | | 评论氛围好吗？粉丝是玩梗还是刷屏？ |
| 内容可持续性 | | 这个风格播一年会不会腻？有成长空间吗？ |
| 表达能力 | | 讲故事/抛梗/接话能力怎么样？ |
| PK 能力 | | 会不会打PK？PK时互动和营收表现如何？ |
| 短视频能力 | | 主页短视频质量如何？更新频率？有没有爆款？ |

**判断**：
- 总分 ≥ 36 且没有 2 分以下项 → 强烈推荐
- 总分 27-35 → 有潜力，需要培训和包装
- 总分 ≤ 26 → 风险较大

---

## Step 3：商业评估

| 评估项 | 结果 |
|--------|------|
| 当前有无经纪约/竞业限制？ | |
| 期望分成比例？ | |
| 签约成本预估（保底/扶持金/抖加投放预算）？ | |
| 预计回本周期？ | |
| 变现路径是否单一？（只靠直播礼物，还是有商单/带货/周边/IP潜力） | |
| 粉丝付费意愿？（看历史礼物收入和粉丝团人数） | |
| 是否愿意配合工会的 PK 和活动安排？ | |

---

## Step 4：风险判断

| 风险项 | 高/中/低 | 说明 |
|--------|----------|------|
| 竞业风险 | | 有无现有合约纠纷？ |
| 稳定性风险 | | 有无断播史？三次元职业/学业影响？ |
| 人品风险 | | 有无争议言论史？粉丝圈风评？ |
| 成本风险 | | 保底+投放费是否超出工会预算安全线？ |
| 赛道风险 | | 这个赛道在抖音是否已经饱和？ |
| 平台适配风险 | | 其风格是否匹配抖音流量逻辑？ |

---

## Step 5：给出结论

用下方模板，必须包含明确建议：

```
【评估对象】XXX（抖音，粉丝 XX 万）
【初筛结果】达标 6/6 项，进入评估
【内容评分】总分 36/45
  - 亮点：歌力强+聊天气质好，人设「社恐歌姬」差异化明显
  - 短板：直播时长偏短（场均 1.5h），短视频更新太慢，需沟通是否愿意加强
【商业判断】
  - 期望分成 50%，无保底要求，成本可控
  - 预计回本周期 2-3 个月
【风险评估】
  - 竞业风险低 / 稳定性中（大三在读）/ 成本风险低
【最终建议】
  ✅ 建议签约，定位「歌势+治愈系」
  签约后重点：1) 沟通直播时长提升至 2.5h  2) 安排短视频团队跟进  3) 培训PK技巧
【签约后 30 天数据目标】
  - 场均礼物收入 ≥ 2,500 元
  - 场均观看人次 ≥ 5,000
  - 月新增粉丝 ≥ 3,000
  - 粉丝团新增 ≥ 100 人
```

## 一条红线

**以下情况一票否决，不用走完整流程：**
- 有明确的黑历史（网暴、诈骗、恶性节奏）
- 当前有未解决的合约纠纷
- 人设涉嫌抄袭/碰瓷知名 IP
- 要求高额保底但数据不支撑
