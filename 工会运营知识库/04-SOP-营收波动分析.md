# 1.4 营收波动分析 SOP

> **触发条件**：工会整体营收周环比波动超 ±20%，或月度营收连续 2 个月下滑

---

## Step 1：拆解营收结构

先把总营收拆开看，问题出在哪一层：

```
工会总营收
├── 主播 A：占比 X%，环比 Y%
├── 主播 B：占比 X%，环比 Y%
├── ...
└── 新主播贡献：占比 X%
```

再拆每个主播的营收来源：

| 来源 | 占比 | 环比 | 说明 |
|------|------|------|------|
| 礼物打赏 | | | 核心收入来源，反映广泛付费意愿 |
| 心愿礼物/定制礼物 | | | 高客单价，依赖少数大哥 |
| 粉丝团/守护 | | | 月度稳定收入，核心粉丝粘性指标 |
| PK 收入 | | | PK 时段的爆发收入，不可持续对比 |
| 活动/生日会等 | | | 一次性爆发，不可持续对比 |

---

## Step 2：定位波动类型

| 波动类型 | 特征 | 常见原因 |
|----------|------|---------|
| 单主播暴跌 | 只有 1 个主播跌，其他正常 | 走 SOP 1.1 |
| 全工会普跌 | 多数主播同时跌 | 平台流量变化、淡季、竞品活动 |
| 大哥波动 | 高额礼物剧烈变化 | 1-2 个大哥的行为决定，不代表趋势 |
| 结构性下滑 | 营收结构变差（只靠大哥大礼物，普通礼物少） | 粉丝付费结构不健康 |
| 季节性波动 | 去年同月也低 | 正常，不需过度反应 |

**核心判断逻辑**：
- 大哥波动（±30% 但来自 1-2 人）→ 不用慌，记录追踪即可
- 普通礼物连续下滑 → 危险信号，核心粉丝在流失
- 全工会普跌 → 先看平台大盘，再看竞品，最后找自身原因

---

## Step 3：健康度诊断

用这套指标判断工会营收结构是否健康：

| 指标 | 健康值 | 警戒值 | 当前值 |
|------|--------|--------|--------|
| Top1 主播营收占比 | <40% | >60% | |
| Top3 主播营收占比 | <70% | >85% | |
| 大额礼物（单笔500元以上）占比 | 30-50% | >70% | |
| 月度付费用户数 | 增长或持平 | 连续3月下降 | |
| 粉丝团总人数 | 增长或持平 | 连续3月下降 | |
| 新主播（签约3月内）营收贡献 | >10% | <5% | |

**解读**：
- Top1 占比 >60% → 单点依赖太高，该主播一出问题工会就崩
- 大额礼物占比 >70% → 营收靠大哥心情，抗风险能力差
- 新主播贡献 <5% → 造血能力不足，需要加速新人培养
- 粉丝团人数下降 → 核心付费用户池在萎缩，比礼物收入下降更值得警惕
